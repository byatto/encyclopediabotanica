    Encyclopedia Botanica

    A personal, offline-first houseplant care catalogue. Reference data (family, care requirements, pests, origins) lives in js/plants.js and is the same on every device. Anything you fill in here — acquired dates, locations, notes — is saved only on this device.

    Install

    On Android Chrome: tap the ⋮ menu → Add to Home screen / Install app. Once installed it works fully offline.

    Your data

    This browser isn't persisting saved data (private/incognito mode, or storage is disabled) — anything you log will be lost when you close the app.

    Care-log entries and notes live in this browser's local storage, on this device only. Export a backup occasionally, especially before reinstalling or switching phones.

    Print / PDF

    Need paper copies or a PDF of the full catalogue? Use the print view — same data, A4 layout.

    Adding a plant

    Copy new-plant-prompt.md into any AI assistant, paste the generated record into js/plants.js, then reload. Full instructions are in that file and in README.md.
